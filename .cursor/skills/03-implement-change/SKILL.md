# Implement change

Implement only the approved plan at `requests/<ticket>/02-plan/plan.md`.

- Keep the diff minimal: change only what the plan requires.
- Do not weaken the acceptance criteria in `requests/<ticket>/01-spec/TASK.md`.
- Do not expand scope beyond the plan.
- Do not invent work the plan did not approve.
