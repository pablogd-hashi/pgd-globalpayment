# Implement change

## When to Use

- The plan at `requests/<ticket>/02-plan/plan.md` has been approved
- The user asks to implement the planned change

## Instructions

Implement only the approved plan at `requests/<ticket>/02-plan/plan.md`.

1. Keep the diff minimal: change only what the plan requires.
2. Do not weaken the acceptance criteria in `requests/<ticket>/01-spec/TASK.md`.
3. Do not expand scope beyond the plan.
4. Do not invent work the plan did not approve.
